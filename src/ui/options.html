Before opening multiple accounts

  1. Open an AWS console, then use the account menu to turn on multi-session.
  2. Connect your access portal above. Synchronisation saves every discovered profile automatically; use Show in popup to choose your shortcuts.
  3. Choose a light, dark, or system theme and accent color for each profile.

Automatic synchronisation runs every 30 minutes by default while Chrome is running. Change the interval beside your portal. If sign-in expires, the portal opens for normal SSO; complete any Microsoft or MFA prompt and synchronisation resumes.

AWS allows up to five active console identities per browser. You can save more profiles. An open tab does not guarantee its AWS session is still valid.

Console themes use the page’s native styling where supported. Some services and embedded frames may keep their own appearance. Profiles are matched by both account and permission set.

No backend or telemetry. No passwords, cookies, access keys, or SSO tokens are collected. Portal access is requested only when you grant it.
