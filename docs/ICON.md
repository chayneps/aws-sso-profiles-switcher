# SSO thought-cloud icon

Artwork created with the built-in image-generation tool using the user's
attached AWS cloud logo as the palette reference. The new mark uses an orange
outline, light orange cloud and dot interiors, dark navy lowercase `sso`, and two
tiny thought dots at each lower corner (four total). The Amazon smile/arrow and
`aws` lettering are absent.

The first `s` and last `o` are small plain letters raised to the same eye line.
The middle `s` stays larger and lower, forming the nose. There are no added
pupils, glints, or eye details.

The full-size selected artwork is saved in `assets/sso-icon.png`. Packaged PNGs
at 16, 32, 48, and 128 pixels are saved in `src/icons/`. The build copies those
reviewed files into `dist/icons/`, so builds never regenerate or replace the
artwork. The toolbar, extension listing, popup, and Manage page share this icon.
The extension remains v1 (`1.0.0`).

To export the sizes again on macOS, use `sips -z SIZE SIZE assets/sso-icon.png
--out src/icons/SIZE.png`, replacing SIZE with each required dimension. Preserve
the PNG alpha channel.
